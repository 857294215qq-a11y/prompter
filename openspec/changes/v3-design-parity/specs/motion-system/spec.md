# Spec Delta

## ADDED Requirements

### Requirement: 单一缓动与时长档位
系统 SHALL 只使用一条缓动 cubic-bezier(.32,.72,0,1)（CSS 变量 `--ease`），并以 CSS 变量提供四档时长：大面 240ms、弹出 200ms（关闭 150ms）、小控件 180ms、文字 160ms。组件 SHALL 引用这些变量，不写死时长或曲线。

#### Scenario: 样式审查
- **WHEN** 检查 ui 样式与脚本中的过渡和动画
- **THEN** 除减少动态效果分支外，所有过渡和动画都引用 `--ease` 与时长变量

### Requirement: 弹出从锚点展开
菜单、弹出框和提示编辑 SHALL 从触发按钮所在位置展开：缩放 0.96→1 加透明度变化，打开 200ms，关闭 150ms。

#### Scenario: 打开提示菜单
- **WHEN** 用户点击“插入提示”
- **THEN** 菜单从按钮下沿展开，动画结束后焦点在第一项

### Requirement: 小控件反馈
开关滑块、分段选择指示、播放 / 文字 / 录制页签指示条 SHALL 以 180ms 滑动到新位置；按钮按下时 SHALL 缩放到 0.97，松开后恢复。

#### Scenario: 切换页签
- **WHEN** 用户从“播放”切到“文字”
- **THEN** 选中底色滑到“文字”，内容随后切换

### Requirement: 跳转平滑滚动
用户发起的跳页、跳段、跳节、回到开头和点句跳转 SHALL 以 320ms 平滑滚动，阅读线位置保持不动。语音跟随驱动的位置变化 SHALL NOT 使用该动画。

#### Scenario: 下一段
- **WHEN** 播放暂停时用户按 D
- **THEN** 画面在约 320ms 内滚动到下一段，阅读线不动

### Requirement: 倒数与文字动效
倒数每一拍 SHALL 用 240ms 让数字从 1.15 倍缩到原大并淡入；插入提示、标记或取消重点、读过变暗 SHALL 用 160ms 的透明度或底色过渡，不产生位移。

#### Scenario: 倒数
- **WHEN** 开始提词且倒数设置为 3 秒
- **THEN** 3、2、1 依次出现，每拍有缩放淡入，结束后开始滚动

### Requirement: 减少动态效果
系统偏好减少动态效果时，所有过渡 SHALL 改为 120ms 透明度变化，不做位移、缩放或平滑滚动，所有状态 MUST 能正常到达。

#### Scenario: 开启减少动态效果
- **WHEN** 系统开启减少动态效果，用户打开菜单、切换侧栏并跳段
- **THEN** 菜单与侧栏只淡入淡出，跳段瞬间到位，最终状态与默认模式一致
