# 提词器

单文件网页提词器（`index.html`），用浏览器打开就能用，不需要安装。

## 功能

- 播放 / 暂停 / 停止，开始前可倒数（0 / 3 / 5 / 10 秒）
- 语速（字/分），或输入目标时长自动算语速；实时显示已用时间、剩余时间和进度
- 字号、行距、左右留白、对齐方式、三种配色、阅读线位置
- 水平 / 垂直镜像，再点一次取消
- 读过的句子自动变暗
- 全屏，提词时保持屏幕常亮
- 稿子和设置自动保存在浏览器里，可以导入 `.txt`

## 分段重录

录了一大段，只有后面一小段要重录时，不用从头再等：

- **进入提词画面不会马上开始**，准备好了再按空格或点 ▶
- **每节读完自动暂停**：读到下一个 `#` 小节标题就停下，按空格继续下一节
- **重录本节**：按 `R` 或点「重录本节」，回到这一节开头重新倒数开始
- **语音跟随**：按 `G` 或点「语音跟随」，字幕跟着你说话的进度走，停顿时字幕也停。用浏览器自带的语音识别，需要联网；推荐 Safari 或 Edge，Chrome 的识别服务在国内可能连不上
- **网页内录像**：按 `C` 或点「录像」打开前置摄像头。每次从开始到暂停存成一条视频，按「第2节-标题-第3条」命名。电脑上录完自动下载；手机上在「目录 → 录好的片段」里点保存，可以直接存到相册

- **从光标处开始**：在编辑页把光标放到要重录的位置，点「从光标处开始」
- **点句子跳转**：提词画面里直接点任意一句，从那一句开始
- **翻页**：上一页 / 下一页，上一段 / 下一段，上一节 / 下一节
- **小节**：稿子里以 `#` 开头的一行是小节标题，可以在「目录」里一键跳转
- **书签**：按 `B` 在当前句加书签，按数字键 `1`–`9` 跳回
- **进度条**：点击或拖动，进度条上会标出小节和书签的位置
- 在画面上拖动或滚动鼠标滚轮，也能微调位置

## 快捷键（翻页笔通常发送 PgUp / PgDn 或左右方向键）

| 按键 | 作用 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← → / PgUp PgDn | 上一页 / 下一页 |
| ↑ ↓ / 滚轮 | 微调位置 |
| A D | 上一段 / 下一段 |
| Q E | 上一节 / 下一节 |
| R | 重录本节 |
| Home | 回到开头 |
| G | 语音跟随 开 / 关 |
| C | 录像 开 / 关 |
| + − | 加速 / 减速 |
| [ ] | 字号小 / 大 |
| M V | 水平 / 垂直镜像 |
| B | 在当前句加书签 |
| 1–9 | 跳到第 N 个书签 |
| L | 目录与书签 |
| F | 全屏 |
| Esc | 返回编辑 |
| Ctrl/⌘ + Enter | 在编辑页开始提词 |

## 安装成 App

打开 https://857294215qq-a11y.github.io/prompter/ 后：

- **安卓 / 电脑（Chrome、Edge）**：点编辑页的「安装到桌面」，或浏览器地址栏右侧的安装图标
- **iPhone / iPad（Safari）**：点「分享」→「添加到主屏幕」

安装后从桌面图标打开，全屏显示，没网也能用（语音跟随除外）。

## 部署

在仓库 Settings → Pages 里选择从 `main` 分支根目录发布，就能用 `https://<用户名>.github.io/prompter/` 打开，手机和平板也能用。
