# Proposal

## Why

V3 的视觉框架已经基本落到 Web/PWA 与 Android 版里，但 Figma 修订副本（文件 oa1czDyPOMjSdkSerE3bNW，页面“05 · V3 修订副本”）又暴露并修正了一批问题：工具栏三个格式工具的行为不好用；开始位置用选择框表达两个按钮的事；侧栏开关和工具栏对不齐、收起后重叠；提词“更多”菜单和底栏信息重复；版本冲突会在提词途中打断；指定曲线 cubic-bezier(.32,.72,0,1) 只用在少数地方；macOS 27 的原生控件样式没有用上。用户已在 Figma 中逐项确认这些修订，现在要求把它们完整做进软件。

结论是在现有代码上渐进改造，不推倒重写：播放、遥控传输、语音跟随、录像、置顶小窗等引擎能力已经可用，并由 30 项测试覆盖；差距集中在呈现层和交互规则上。但 index.html 里约 2,086 行的内联脚本是继续补状态的主要风险，所以先做一次不改变行为的模块拆分。

## What Changes

- **工具栏行为**：小节按钮显示当前行状态；重点只作用于选区、可取消，没有选区时不可用，不再插入“重点”占位字；提示改为从菜单选择预设插入到光标处，不再把选中的正文变成提示；点已有提示可改文字或删除。
- **开始操作**：去掉“开始位置”选择框，改为“开始提词”（从头）与“从光标处开始”两个按钮。**BREAKING**：移除 v3-editor-space 中的选择框和对应存储项。
- **侧栏开关**：固定 36px 槽位，与工具胶囊同一中线；打开、收起位置不变；收起与展开使用不同图标；侧栏收起时工具栏让位，不再重叠。
- **编辑页排版**：小节标题字号高于正文；目标时长旁说明它会换算语速；应用设置使用齿轮图标。
- **提词画面**：正文列与顶部胶囊对齐；底栏保持纯图标并居中，计时标签提高到 12px；“更多”改为带图标和勾选状态的分组菜单，去掉与顶栏和底栏重复的项；重录本节使用逆时针图标；修复开始提示与底栏重叠。
- **悬停说明**：所有纯图标按钮提供名称与现有快捷键的悬停说明，键盘聚焦时同样可见。
- **动效**：全局一条曲线、四档时长；补齐菜单从锚点展开、页签与分段指示滑动、按下反馈、跳转平滑滚动、提词栏隐藏、倒数和悬停说明的动效；减少动态效果时保留透明度变化。
- **原生观感**：菜单、弹出框、开关、分段、输入框、单选和按钮按 macOS 27 组件的尺寸、圆角、材质与字号重做 CSS；Figma 中这些部件已经换成库组件，作为对照来源。
- **结构**：把内联引擎拆成 ES 模块，对外 api 不变，作为上述改动的第一步。

## Capabilities

### New Capabilities

- `reader-controls`：提词画面的阅读列、顶栏、底栏、“更多”菜单、开始提示与提词栏自动隐藏。
- `icon-tooltips`：纯图标按钮的悬停与聚焦说明。
- `motion-system`：全局缓动、时长档位、各类部件的动效与减少动态效果规则。
- `native-controls`：菜单、弹出框、开关、分段、输入框、单选和按钮的 macOS 27 风格基线。

### Modified Capabilities

- `editor-actions`：格式工具行为、开始操作改为两个按钮。
- `editor-workspace`：侧栏开关槽位与图标、编辑页标题层级、动效引用新的 motion-system。

## Impact

- 代码：index.html（拆出内联脚本）、ui-v3.js、ui-v3.css、新增 src/ 下的模块、tests/ui.test.cjs、sw.js 缓存版本、assets/v3 新增图标（rotate-ccw、panel-left-open、panel-right-open、settings、chevron-*、picture-in-picture-2、trash-2）。
- 数据：移除开始位置选择的存储项，读到旧值时忽略；稿件格式不变，提示仍以 `[文字]` 存储。
- 不在本次范围：双向稿件同步与“两个版本”选择（目前代码没有同步后端，只保留设计，见 design.md）；用户可选的连接方式（目前由程序在中转和局域网之间自动选择）；原生 Mac/Windows 外壳；手机遥控的 iOS 27 组件替换。
