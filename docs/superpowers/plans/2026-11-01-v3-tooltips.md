# V3 Icon Tooltips (Task Group 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace native `title` tooltips on icon buttons with one tooltip component whose copy comes from the Figma tooltip table, and prove every listed shortcut really works.

**Architecture:** A new classic script `src/ui/tooltips.js` (own IIFE scope, loaded after `ui-v3.js`, before `src/boot/ready.js`) holds the copy table and a delegated controller on `document` (pointer and focus events), so it needs no init order and covers buttons `ui-v3.js` creates later. Visible text is name + shortcut; for screen readers the name stays the button's `aria-label` and the shortcut alone is linked through `aria-describedby`.

**Tech Stack:** Vanilla JS classic scripts, CSS, jsdom 26 + node:test.

**Spec:** `openspec/changes/v3-design-parity/specs/icon-tooltips/spec.md`, decision 6 in `openspec/changes/v3-design-parity/design.md`. Copy table: Figma `Tooltip 文案表` 2177:2292 (copy page) / 2205:5725 (formal page). Style: examples 2177:1899 and 2177:2091.

## Global Constraints

- Timing: hover shows after 500ms with a 120ms fade; keyboard focus shows at once; pointer leave, click, Escape or blur hide at once. No tooltip on touch-only devices (`(hover: none)`).
- Style (macOS 27 Tooltip): height 18px, padding 3px 6px, 11px text `#1a1a1a`, background `rgb(236 236 236 / .88)` with `backdrop-filter: blur(20px)`, shadows `0 2px 8px #0002, 0 0 2px #0002`, radius 4px; dark appearance uses `rgb(51 51 51 / .88)` with `#f5f5f7` text. Placement: 4px below the button, centred; buttons in `.bottombar` get it 8px above; always clamped 8px inside the viewport.
- Shortcut glyphs: Mac shows `⌘Z`, `⇧⌘Z`, `⌘ 回车`; elsewhere `Ctrl+Z`, `Ctrl+Shift+Z`, `Ctrl+回车`.
- Use the shared curve `var(--ease)`. Run `npm run stamp` before every commit that touches `index.html`, scripts or styles; add `src/ui/tooltips.js` to `VERSIONED` in `sw.js`.

## Review Focus

1. A button whose `aria-label` changes while its tooltip is open (sidebar toggle clicked by keyboard) — the tooltip hides on click, and on the next focus shows the new name. (Task 2 test `tooltip follows the toggle's new name`.)
2. Hover → click → the 500ms timer from the hover must not re-show the tooltip after the click. (Task 2 test `a click cancels a pending hover tooltip`.)
3. Existing `aria-describedby` (format help, `startCaretHelp`) must be kept, with the shortcut id appended, not replaced. (Task 2 test `existing descriptions are kept`.)
4. Buttons hidden or inside a closed menu never show a tooltip; the tooltip never covers the button it describes. (Task 2 test and the browser check.)
5. Non-Mac platforms see `Ctrl` glyphs. (Task 1 test `Windows shows Ctrl shortcuts`.)
