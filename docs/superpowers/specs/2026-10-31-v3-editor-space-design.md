# V3 桌面编辑空间与操作说明

状态：用户已于2026-10-31批准。2026-10-31。目标项目：prompter；Figma：oa1czDyPOMjSdkSerE3bNW。prompter-v3作为历史实现参考，不双写两个工程。

## Intent

用户选择同屏看到更多稿件内容，并同意方案1：自适应单栏，限制最长行宽。保持正文字号，侧栏收起与专注时扩宽正文、减少换行。最新指令取代此前“所有状态正文坐标和624px行宽固定”的约定。

## Approaches

1. 自适应单栏、限制最长行宽：用户已选；兼顾空间利用与逐行阅读。
2. 单栏铺满：超宽屏行长难读，未选。
3. 宽屏双栏：连续编辑与跨栏选择复杂，未选。

## Layout

以下具体数值为本会话提案，待审批及视觉验证。

- 桌面侧栏外距8px保留。中间工具胶囊顶部与两侧卡片顶部齐平；两侧开关同一水平中心线，32px图形按钮置于44px可点击区域。浅深色一致。
- 两侧开关固定于编辑器视口左右锚点，独立于侧栏与正文布局，展开/收起不得更换父容器或图标语义。正文与侧栏标题避开各自开关。
- Web/PWA沿用系统实际窗口栏，移除模拟Windows标题栏占位；Figma原生Windows参考保留紧凑24px标题栏与4px间隔，标明原生用途。Mac原生参考保留真实窗口按钮；Web不模拟它们。
- 正文字号17px、现有行距不因收起侧栏变化。标题与正文共用自适应列，工具栏左端对齐正文；正文默认利用可用宽度，上限约960px，剩余空间居中分配。960px是初始提案，需中文长稿实际验证，可由实施者在880–1040px内调整并记录。
- 左栏232px、右栏296px，栏与正文间距24px。收起左/右栏释放其宽度及间距；专注模式释放两侧。1440px窗口双展开正文约848px，双收起约960px；避免再次固定为624px。
- 连续编辑保持同一个文本节点和DOM选择，重排前记住光标/可见段落及其视口纵向位置；重排后保持该段可见，不将scrollTop机械归零。横向移动是允许的，突然跳到其他段落不允许。
- 手机和平板沿用现有断点和抽屉语义；本轮不扩展桌面栏结构到手机。

## Motion

- 指定cubic-bezier(.32,.72,0,1)，侧栏进出和工具组位移建议240ms；关闭可缩短到180ms。减少动态效果偏好下禁用位移/缩放。
- 固定开关不参与位移。正文真实换行一次完成，不逐帧缩放文字；需要衔接时仅对容器使用短暂位移/淡入，不将截图当成可编辑正文。
- 连续开关打断旧动画，最终可见性、inert、aria-expanded与实际状态一致。
- 先做Figma开/合/专注关键状态和曲线验证；Figma Motion可用时制作一组代表性演示。真实重排、滚动、光标与快速重复点击必须在本地运行页面验证，Figma不是替代。

## Actions

本轮保留既有业务能力，先修正文案与反馈，不凭猜测删除功能。

- 小节 → “小节标题”：切换当前行标题/正文；重点 → “标记重点”：作用于选中文字；提示 → “插入提示”：插入不计入朗读字数的停顿等提示。
- 工具按钮保留紧凑外观，补准确title、键盘可聚焦说明和可访问名称；选中态仅用于实际可切换状态。
- 专注编辑：隐藏两侧栏，退出恢复原组合；全屏：仅表示进入系统全屏，两者文案和图标不混用。
- “开始提词”与“从当前编辑位置开始”改成明确的一组开始位置选择：“从头开始 / 从光标处开始”，共享主按钮“开始提词”。默认保留当前已实现的开始位置规则；用户显式选择可覆盖，缺少有效光标时回到开头并显示说明。
- 右侧“文字”页签明确说明“仅影响提词画面”，避免字号56px与编辑器17px混淆。语音、录像、同步仍只报告真实权限与连接状态。

## Acceptance

- 1440×900和1920×1080，Mac/Windows参考、浅深色、四种侧栏组合、专注往返：无多余顶部空条，两侧开关同高且坐标不跳，卡片8px外距。
- 同一长稿与字号下，收起侧栏后正文列不变窄、正文换行减少；在双展开尚未达到行宽上限时，双收起同屏可见字数高于双展开；1920px等已经达到行宽上限的窗口允许内容量不再增加，释放的区域用于留白。不得为追求字数无限拉长文本行。
- 重排保留稿件内容、选择和阅读/编辑位置；保存、撤销、开始提词及专注退出不回归。
- 动画使用指定曲线，快速点击无残留遮挡或不可点击控件；reduced-motion有效。
- 有疑义按钮具备可理解名称、操作结果与状态反馈；键盘用户可获取解释。
- 更新OpenSpec change（中文内容，结构标题与SHALL/MUST保留英文）、Figma和本地实现说明；保存新证据。用户视觉签收独立进行。

## Scope and Builder Decisions

沿用HTML/CSS/JavaScript、Capacitor与现有业务引擎，不新增框架。保留存储键、稿件格式和权限处理。实现者负责布局机制、测试组织、精确动效及安全恢复方式；任何业务功能删除、原生桌面工程新增或重新设计移动端均不在本轮范围。

实施复核：已由独立审阅者检查。发现1920px下行宽上限与“必须增加字数”冲突，已明确达到上限后允许不再增加；该取舍是本会话建议，待用户随本文审批。
