# Spec Delta

## ADDED Requirements

### Requirement: macOS 27 控件基线
菜单、弹出框、开关、分段选择、输入框、单选和按钮 SHALL 按 macOS 27 库组件的尺寸、圆角、字号和状态色实现：菜单圆角 12、行高 24、13px 字号、带勾选列和图标列；弹出框圆角 20，使用模糊半透明材质和分层阴影；中文使用 Noto Sans SC 回退。深色背景上的菜单文字 SHALL 保持正常混合模式，以保证可读。

#### Scenario: 与 Figma 对照
- **WHEN** 在 1440×900 下打开“更多”菜单、插入提示菜单和设备弹出框，并与画板 2164:478、2173:1241、2164:733 截图对照
- **THEN** 尺寸、圆角和行高偏差不超过 2px，文字完整可读

#### Scenario: 材质降级
- **WHEN** 浏览器不支持 backdrop-filter，或设备开启降低透明度
- **THEN** 菜单与弹出框改用不透明背景，文字对比度不低于 4.5:1

### Requirement: 设备弹出框
设备与遥控 SHALL 以锚定在“设备”按钮下方的弹出框呈现：已连接设备及其状态点、管理已配对设备、配对另一台设备、“当作遥控器使用”开关、当前线路（只读显示附近直连或中转）、“发送当前稿件到平板”按钮。弹出框 SHALL NOT 带关闭按钮，点击外部或按 Esc 关闭。

#### Scenario: 打开设备弹出框
- **WHEN** 用户点击“设备”
- **THEN** 弹出框出现在按钮下方，不遮挡右侧参数卡的标题，当前线路与实际连接一致

#### Scenario: 断开连接
- **WHEN** 遥控设备断开
- **THEN** 状态点和文字同时更新，“发送当前稿件到平板”不可用
