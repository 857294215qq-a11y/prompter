现状：index.html 内联约 2,086 行引擎脚本（122 个函数），负责播放、导航、遥控（MQTT 中转加 WebRTC 局域网）、语音、录像和置顶小窗。ui-v3.js（543 行）通过 `window.initPrompterV3(api)` 接管呈现，ui-v3.css（386 行）覆盖样式。格式工具在 ui-v3.js 的 `[data-format]` 点击处理中实现：没有选区时插入“重点”“停顿”占位字，有选区时直接包裹。提词栏 2.5 秒无操作会自动隐藏（`poke`/`idle`），但没有过渡。`--ease` 已定义，只被 animateSurface、工具栏平移、开关和提示条使用。

## Goals / Non-Goals

**Goals**

- 把修订副本中用户已确认的行为与视觉做进 Web/PWA 和 Android 包，在 1440×900、1194×834、390×844 下与对应画板对照。
- 先做不改变行为的模块拆分，让后续改动可以按功能测试。
- 动效与减少动态效果规则统一来自 motion-system。

**Non-Goals**

- 不实现双向稿件同步，也不实现“两个版本”选择流程。画板 2166:899 保留为将来做同步时的设计。
- 不新增用户可选的连接方式。设备弹出框中的分段控件改为只读显示当前线路（附近直连 / 中转），不作为开关。
- 不引入前端框架，不改存储的稿件格式、传输协议或配对方式。
- 不做原生 Mac/Windows 外壳，不替换手机遥控为 iOS 组件。

## Decisions

### 1. 先拆模块，后改行为

内联脚本按现有 18 个分区拆成 `src/engine/NN-name.js`，作为**按原顺序加载的普通脚本**，不用 ES 模块。原脚本是一个立即执行函数，各分区共用并反复重新赋值同一批变量（library、currentId、S、v3、editMode、marks 等）。ES 模块不能给导入的变量重新赋值，要改就得重写这些赋值，与"不改行为"冲突。普通脚本的顶层 let/const 共享同一个全局词法作用域，代码可以逐字搬运。每个文件顶部写 `'use strict'`。

代价有两点。其一，函数提升只在单个文件内有效，启动时执行的语句不能调用后面文件里的函数；这由浏览器、安卓 App、直连链接、中转链接四种启动测试兜住。其二，顶层函数会挂到 window 上，所以 `stop` 改名为 `stopPlayback`，以免覆盖 `window.stop`；对外 api 的 `stop` 键不变。

ui-v3.js 暂不拆分：它的 `$` 等名字会和引擎在共享作用域里冲突，543 行也还读得过来。第 4–6 组新增的 tooltip、菜单、动效等组件各自成为独立文件，自带作用域，通过 `initPrompterV3` 收到的 api 与引擎通信。构建脚本复制 src 目录，sw.js 的缓存清单逐项列出引擎文件并提升版本，由测试核对页面加载的每个本地脚本和样式都在清单里。拆分提交不改任何行为，原 30 项测试和 build:web 必须原样通过。

备选方案是不拆、直接在内联脚本里改。没有选它，因为工具栏、提词栏和动效的改动会同时触及引擎与呈现两层，没有边界时回归难以定位。

### 2. 格式工具

- **小节**：保持当前行切换。光标或选区起点在 `#` 行时，按钮为 `aria-pressed="true"`，样式取强调色 12% 底和强调色图标。
- **重点**：没有选区时 `disabled`。选区已经完整位于 `**…**` 内时为按下态，点击去掉标记，否则包裹。不再插入任何占位文字。
- **提示**：点击打开锚定菜单，预设为停顿、换气、看镜头、放慢、加重，以及“自定义提示…”（输入框，1–12 字，与现有解析上限一致）。在光标处插入 `[文字]`；有选区时先把光标移到选区末尾，不改动正文。
- **已有提示**：点击 `.editor-cue` 打开小弹出框，内含输入框和删除按钮。回车确认，Esc 取消，清空等同删除。
- 所有改动走现有 `replaceSelectionAtBuffer` 与撤销历史，一次操作产生一个撤销步骤。

### 3. 开始操作

右栏底部改为两个按钮：次按钮“从光标处开始”（⌘/Ctrl+Enter，调用 `api.enter(true)`），主按钮“开始提词”（`api.enter(false)`）。没有有效光标时，次按钮 `disabled`，悬停说明给出原因。删除 `#startPosition` 及其存储，读到旧值时忽略。

### 4. 侧栏开关

两个开关从侧栏 DOM 中移到编辑器上层的固定槽位，36×36，与工具胶囊（高 36）同一中线。Web 版左槽距左 8px；macOS 原生外壳以后预留红黄绿区，左槽为 x=96。右槽距右 16px。图标随状态切换：打开时为 panel-*-close，收起时为 panel-*-open；`aria-label` 与悬停说明同步为“收起…”或“展开…”。侧栏收起时，工具栏容器的内边距让出槽位加 8px。

### 5. 提词画面

- 阅读列左边缘与宽度对齐顶部胶囊，仍受字号与现有最大宽度约束。
- 底栏保留现有图标与顺序，整体居中；“已用 / 剩余 / 进度”标签改为 12px、次级色。
- “更多”菜单按 macOS 菜单结构：
  - “画面”组：水平镜像、垂直镜像，左侧勾选表示开启，带图标和快捷键 M / V。
  - “窗口”组：打开置顶小窗、连接遥控器、全屏（F）。
  - 移除语音跟随、摄像头、跳段、跳节和“完成”，因为顶栏和底栏已经有这些操作。
  - 菜单定位在胶囊下方 8px，右对齐胶囊。
- 重录本节使用 rotate-ccw 图标。
- 开始提示（“准备好了 · 空格开始”）放在阅读线附近，不与底栏重叠；测试中用两者的边界矩形不相交来断言。

### 6. 悬停说明

自定义 tooltip 组件替代原生 `title`（原生 title 无法控制延迟和样式，读屏也可能重复读）。文案来自一张表：名称加上 index.html 键盘处理中已有的快捷键，与画板 2177:2292 一致。触发条件是指针悬停 500ms 或键盘聚焦，Esc、离开或点击时立即隐藏。按钮的可访问名称就是 tooltip 的名称，tooltip 通过 `aria-describedby` 只补充快捷键。触屏设备不显示。

### 7. 动效

| 档位 | 时长 | 用于 |
|---|---|---|
| 大面 | 240ms | 侧栏、对话框、提词栏出现与隐藏 |
| 弹出 | 开 200ms / 关 150ms | 菜单、弹出框、提示编辑，从锚点缩放 0.96→1 加透明度 |
| 小控件 | 180ms | 开关、分段、页签指示条、按下缩放 0.97 |
| 文字 | 160ms | 提示与重点的出现、读过变暗 |

另有：滚动跳转 320ms，由 rAF 驱动且阅读线不动；倒数每拍 240ms；悬停说明延迟 500ms、淡入 120ms。所有时长写成 CSS 变量，统一使用 `--ease`。减少动态效果时只保留 120ms 透明度变化，不做位移、缩放和平滑滚动，替换现在“全部 transition: none”的做法。

### 8. 原生观感

不尝试在 Web 中复刻 Liquid Glass 的折射效果。菜单与弹出框采用 macOS 27 的尺寸：圆角 12/20，菜单行高 24，13px 字号，左侧勾选列与图标列；背景使用 backdrop-filter 模糊加半透明底和三层阴影。开关、分段、单选和按钮按库组件的尺寸与状态色重做 CSS，并以 Figma 截图对照。中文统一使用 Noto Sans SC 回退。

## Risks / Trade-offs

- [模块拆分引入回归] → 拆分单独成为一个提交，只移动代码不改逻辑；以 30 项测试、构建和手动冒烟（播放、配对、录像、置顶小窗）把关。
- [ES 模块在 Android WebView 或离线缓存中加载失败] → build:web 产物在 Capacitor 同步后真机打开验证；sw.js 缓存清单由构建生成。
- [自定义 tooltip 影响读屏] → 名称放在 `aria-label`，快捷键放在 `aria-describedby`，用读屏抽查。
- [平滑滚动与语音跟随抢位置] → 语音跟随驱动的位置变化不走 320ms 动画，只有用户发起的跳转才平滑滚动。
- [backdrop-filter 性能] → 只在菜单和弹出框打开时启用；低端设备上退回不透明背景。

## Migration Plan

按 tasks.md 的顺序依次做：模块拆分 → 编辑区行为 → 提词画面 → 悬停说明 → 动效 → 原生观感 → 对照验证。每组独立提交并通过测试，回滚时退回对应提交即可。旧的开始位置存储值直接忽略，不需要迁移数据。
