# 第 5 组核对（内置浏览器，1440×900）

## 任务 2：弹出与小控件

- 播放 / 文字 / 录制页签：一个蓝色指示块（宽 1/3）在文字下方，选「文字」后 `--seg-i` 变为 1、指示块 translate 100%，按钮本身底色透明；截图确认文字可读、指示块不遮挡文字。
- 对齐分段：两项时指示块宽 50%，随选中项移动。
- 插入提示菜单：打开动画 200ms、曲线 cubic-bezier(0.32, 0.72, 0, 1)；`transform-origin` 16px 0（按钮中心在菜单左边 15–16px 处，菜单顶边），即从按钮下沿展开。

## 审阅后修复：连接方式分段（网页版，「附近设备」隐藏）

- 选「同一网络 / 热点直连」：`--seg-n` 2、`--seg-i` 0，指示块 x=536、宽 188；选项 x=536、宽 184。
- 选「通过互联网」：`--seg-n` 2、`--seg-i` 1，指示块按变量应在 536 + 188 = 724；选项 x=720。窗格在后台时 180ms 滑动停在起点，所以这里按变量算位置。
- 修复前隐藏的第一项也被计数，指示块只有 1/3 宽且错位，选中的白字一半落在灰底上。
