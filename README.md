# 提词器

单文件网页提词器（`index.html`），用浏览器打开就能用，不需要安装。

## V3 界面更新

现有 Web/PWA 与 Android 共用 V3 界面：可搜索的稿件侧栏、富文本编辑、播放 / 文字 / 录制参数页签、浅深色外观、可收起侧栏、专注编辑，以及手机和平板布局。应用外观与提词阅读配色独立。Mac、Windows 原生桌面工程另行开发，网页不模拟系统窗口按钮。

已有稿件、参数和存储键继续兼容；重命名只改名称，导入 `.txt` 会创建新稿件。小节、重点、提示仍以 `#`、`**重点**`、`[提示]` 的纯文本格式保存和导出。点击「小节」可切换当前行的小节/正文格式。书签跟随各自的稿件保存。

本地开发：`npm ci` 后运行 `npm run dev`，访问终端显示的地址。开发用的 localhost 不注册 Service Worker，避免旧离线缓存遮住样式修改；正式部署继续支持 PWA 离线缓存。验证命令为 `npm test` 和 `npm run sync`。PR 的检查会执行回归测试、Android 资源同步和调试 APK 编译；正式 APK 仍由原有 main 分支发布流程生成。

遥控界面显示真实连接状态，断开或锁定时不能发送操作；支持当前句上下文和点句定位。Figma 中演示的双向稿件同步、版本冲突选择不属于现有传输协议，本次没有用演示状态冒充这些能力。语音、录像、附近设备和跨设备连接仍需在目标设备上验收。

## 功能

- 播放 / 暂停 / 停止，开始前可倒数（0 / 3 / 5 / 10 秒）
- 语速（字/分），或输入目标时长自动算语速；实时显示已用时间、剩余时间和进度
- 字号、行距、左右留白、对齐方式、三种配色、阅读线位置
- 水平 / 垂直镜像，再点一次取消
- 读过的句子自动变暗
- 全屏，提词时保持屏幕常亮
- 稿子和设置自动保存在浏览器里，可以导入 `.txt`，可以存多份稿子随时切换
- `**重点**` 高亮显示；`[停顿]`、`【微笑】` 这样的方括号变成小提示标签，不计入字数
- 提词画面里点「改字」或双击句子，直接改错字，回车保存
- 电脑上的 Chrome / Edge 可以开「小窗」：提词放进一个置顶小窗口，叠在 OBS 或会议软件上面

## 分段重录

录了一大段，只有后面一小段要重录时，不用从头再等：

- **进入提词画面不会马上开始**，准备好了再按空格或点 ▶
- **每节读完自动暂停**：读到下一个 `#` 小节标题就停下，按空格继续下一节
- **重录本节**：按 `R` 或点「重录本节」，回到这一节开头重新倒数开始
- **语音跟随**：按 `G` 或点「语音跟随」，字幕跟着你说话的进度走，停顿时字幕也停。用浏览器自带的语音识别，需要联网；推荐 Safari 或 Edge，Chrome 的识别服务在国内可能连不上
- **网页内录像**：按 `C` 或点「录像」打开前置摄像头。每次从开始到暂停存成一条视频，按「第2节-标题-第3条」命名。电脑上录完自动下载；手机上在「目录 → 录好的片段」里点保存，可以直接存到相册

- **从光标处开始**：在编辑页把光标放到要重录的位置，点「从光标处开始」
- **点句子跳转**：提词画面里直接点任意一句，从那一句开始
- **翻页**：上一页 / 下一页，上一段 / 下一段，上一节 / 下一节
- **小节**：稿子里以 `#` 开头的一行是小节标题，可以在「目录」里一键跳转
- **书签**：按 `B` 在当前句加书签，按数字键 `1`–`9` 跳回
- **进度条**：点击或拖动，进度条上会标出小节和书签的位置
- 在画面上拖动或滚动鼠标滚轮，也能微调位置

## 安卓 App（APK）

把网页打包成了安卓 App，不依赖网络。每次更新代码，GitHub 会自动编译，到仓库的 **Releases** 页面下载最新的 `prompter.apk`，手机上点开安装即可（需要允许「安装未知来源应用」）。

App 里多出的功能：

- **附近设备遥控（类似 LocalSend）**：两台装了 App 的设备在同一个 Wi-Fi，或者一台开热点另一台连上去，不需要上网。被遥控的设备点「手机遥控 → 附近设备」，会显示一个 6 位验证码；另一台设备点「当遥控器」，在列表里点这台设备，输入验证码就连上了。配对过的设备下次直接连，断线自动重连；找不到设备时可以手动输入地址。
- 录好的视频直接存到相册（电影 / 提词器）
- 提词时保持屏幕常亮，全屏隐藏状态栏

App 里暂时没有「语音跟随」（安卓网页内核不带语音识别，华为手机也没有谷歌语音服务）。

**签名密钥（只需设置一次）：** 要让新版 APK 能直接覆盖旧版，每次编译必须用同一把密钥。密钥不放在仓库里，而是存在 GitHub 的加密变量中：在仓库 Settings → Secrets and variables → Actions 里添加 `ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_PASSWORD`、`ANDROID_KEY_ALIAS` 四个变量。没设置时也能编译，但用的是临时调试密钥，更新时需要先卸载旧版（本地稿子会丢）。

自己编译：`npm install && npm run sync`，再用 Android Studio 打开 `android/` 目录。

## 手机遥控（网页版）

在提词设备上点「手机遥控」，另一台手机就能当遥控器：播放暂停、翻页、上下段、上下节、重录本节、调语速和字号、加书签，还能看到提词设备正在读哪一句。有两种连法：

**1. 同一网络 / 热点直连（不需要上网，默认）**
两台设备连同一个 Wi-Fi，或者遥控手机连上提词设备开的热点，都行。

1. 在提词设备上点「开始配对」，用遥控手机的相机扫出现的二维码，打开遥控页面。
2. 遥控页面会显示另一个二维码。在提词设备上点「扫描遥控器的码」，摄像头对准它。
3. 连上后，遥控手机就能按了。

扫码不方便时，可以展开「手动配对」，复制链接、粘贴回应码。配对后两台设备直接通信，不经过任何服务器。

遥控手机要先在有网的时候打开过一次本页面（或者装成 App），这样连上没有网络的热点时，遥控页面也能从缓存里打开。

**2. 通过互联网**
扫一个码就行，两台设备都要能上网。消息通过公共 MQTT 服务器（broker.emqx.io）中转，内容用二维码里的密钥端到端加密。配对会记住，下次不用重新扫。

## 安装成 App

打开 https://857294215qq-a11y.github.io/prompter/ 后：

- **安卓 / 电脑（Chrome、Edge）**：点编辑页的「安装到桌面」，或浏览器地址栏右侧的安装图标
- **iPhone / iPad（Safari）**：点「分享」→「添加到主屏幕」

安装后从桌面图标打开，全屏显示，没网也能用（语音跟随除外）。

## 部署

在仓库 Settings → Pages 里选择从 `main` 分支根目录发布，就能用 `https://<用户名>.github.io/prompter/` 打开，手机和平板也能用。
